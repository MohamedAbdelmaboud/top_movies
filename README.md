<!-- Description -->
<p>
  <strong>Top Movies</strong> is a Flutter app built using <strong>BLoC</strong>, <strong>Clean Architecture</strong>, and <strong>SOLID Principles</strong> 🎯.  
  It provides a seamless experience for browsing movies: <em>popular, top-rated, now playing, and upcoming</em>, along with detailed views for each film, cast info, trailers, and personalized recommendations.
</p>
